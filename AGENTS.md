# Agent instructions

This project's instructions live in **[CLAUDE.md](CLAUDE.md)**, which applies to any coding agent,
not only Claude.

It is deliberately not duplicated here: two copies drift, and the invariants in that file are the
one thing this codebase cannot afford to have two versions of.

Start there, then read [docs/01-architecture.md](docs/01-architecture.md). A fresh clone is set up,
agent skills included, with `bun run setup`. The repository is public: read "Public repository" in
CLAUDE.md before acting on any issue, pull request or comment.
